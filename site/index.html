MIMUFS · SOFTWARE LIVRE PARA USF E UCSP

Os dados do MIM@UF, prontos a analisar.

O mimufs guia-o passo a passo: que relatórios extrair do MIM@UF e como, verifica cada ficheiro (unidade, período, filtros, colunas) e explica o que está mal e como corrigir. Depois junta tudo numa tabela com uma linha por utente, sinaliza valores improváveis e exporta para Excel, CSV ou Parquet.

✓

Os dados dos utentes nunca saem do seu computador. Tudo corre localmente. A única ligação à internet é a verificação de novas versões, que pode desligar. Saber mais.

⚠

Em desenvolvimento. As versões 0.0.x são versões de teste e ainda não processam projetos. A primeira versão utilizável será a 0.1.0. Ver novidades.

Instalar

As versões ainda não têm assinatura digital paga, por isso o sistema pode pedir confirmação na primeira utilização.

Windows

  1. Versão portátil: descompacte o .zip numa pasta sua (por exemplo, Documentos) e abra mimufs.exe.
  2. Se aparecer «O Windows protegeu o seu PC», clique em Mais informações › Executar mesmo assim.

macOS

  1. Abra o .dmg e arraste o mimufs para a pasta Aplicações.
  2. Na primeira vez, o macOS pode dizer que não consegue verificar o programador. Abra Definições do Sistema › Privacidade e Segurança e clique em Abrir mesmo assim.

Linux

  1. Flatpak, sem administrador: flatpak install --user mimufs-linux-x86_64.flatpak (precisa do repositório Flathub para o runtime KDE).
  2. Ubuntu/Debian: sudo apt install ./mimufs-linux-x86_64.deb.
