# mimufs

[![CI](https://github.com/diogocarapito/mimufs/actions/workflows/ci.yml/badge.svg)](https://github.com/diogocarapito/mimufs/actions/workflows/ci.yml)
[![License: GPL-3.0](https://img.shields.io/badge/license-GPL--3.0-blue.svg)](LICENSE)

**mimufs** is a free desktop app (macOS, Windows, Linux) for Portuguese family-medicine units (USF/UCSP). It guides a clinician step by step from "I have never used these MIM@UF reports" to a clean, validated, patient-level dataset:

1. **Extraction & import**: click-by-click instructions for each MIM@UF report, then drag & drop the exported files. mimufs recognises each file and checks it (unit, period, filters, columns, truncation, duplicates), and explains what is wrong and how to fix it.
2. **Aggregation**: all files are merged into one dataset, one row per patient.
3. **Data quality**: rule-based suggestions for implausible lab and biometric values. Original values are kept, and every change is logged.
4. **Normalisation**: your own mapping of appointment types.
5. **Export**: XLSX / CSV / Parquet tables for the whole unit or per doctor.

> **Privacy is the core feature.** Everything runs on your computer. Patient data never leaves it. The only network request the app ever makes is an optional check for new versions (`GET https://mimufs.com/version.json`), which you can switch off.

The UI is in Portuguese (PT-PT). Downloads and install notes: **https://mimufs.com**.

## Development

Requires [uv](https://docs.astral.sh/uv/) (it installs Python 3.12 for you). The SClínico PDF reader needs Java 21; release builds ship their own runtime.

```bash
uv sync                                         # install deps (dev included)
git config core.hooksPath .githooks             # enable the "no data files" pre-commit hook
uv run ruff check . && uv run ruff format --check .
uv run mypy src/mimufs/core
uv run pytest                                   # unit + golden + offline e2e
uv run python tests/fixtures/make_fixtures.py   # regenerate synthetic fixtures
uv run briefcase dev                            # run the app from source
```

Rules for contributors are in [`CLAUDE.md`](CLAUDE.md). The most important one: **never commit real patient data.** Test files are synthetic and generated by `tests/fixtures/make_fixtures.py`.
